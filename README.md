### Highlights

- 🧭 Fixed navigation with smooth scrolling between sections

- 🛠️ Project cards, technical skills, and tools
- 🏅 Experience, campus involvement, and certifications

This is a **static website**: no backend, framework, or build step is required.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rajeshwariagrawal23-crypto/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser. Alternatively, use **Live Server** in VS Code for a convenient local preview.

> **Note:** Keep the profile image and résumé PDF in the same directory as `index.html`, with filenames matching the references in the HTML exactly. The current page references `Profile.png` and `Rajeshwari_Agrawal_Resume.pdf` (capitalization matters on some hosting platforms).
